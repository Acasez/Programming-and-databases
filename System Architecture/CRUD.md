Create, Read, Update and Delete, are the main functions of persistent storage, and are often references when talking about [[Databases]] and [[Web API]]. For [[SQL]] the functions correspond to:

| CRUD   | SQL                                                                   |
| ------ | --------------------------------------------------------------------- |
| Create | [INSERT](https://en.wikipedia.org/wiki/Insert_\(SQL\) "Insert (SQL)") |
| Read   | [SELECT](https://en.wikipedia.org/wiki/Select_\(SQL\) "Select (SQL)") |
| Update | [UPDATE](https://en.wikipedia.org/wiki/Update_\(SQL\) "Update (SQL)") |
| Delete | [DELETE](https://en.wikipedia.org/wiki/Delete_\(SQL\) "Delete (SQL)") |
