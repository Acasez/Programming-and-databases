Design patterns are patterns in software [[Development]] that can be used to describe [[System Architecture]]. They are ways to talk about code structure and design. Design patterns can help to write [[SOLID]] code and complying with [[Boochs Metrics]]

There are a number of design patterns, split into Creational Patterns, Structural Patterns, Behavioral Patterns, and the rarer Concurrency, Cloud and Architectural Patterns
