**SOLID** principles are a set of principles for coding in [[Object Oriented Programming]]

## **S**ingle Responsibility Principle
A class should have only one reason to change, and have a single purpose.
## **O**pen/Closed Principle
Classes should be open for extension but closed for modification.
## **L**iskov Substitution Principle
Subtypes must be substitutable for their base types without altering the correctness of the program.
## **I**nterface Segregation Principle
No client should be forced to depend on [[Interface|interfaces]] they don’t use.
## **D**ependency Inversion Principle
High-level modules should not depend on low-level modules. Both should depend on abstractions (interfaces).
