Booch’s metrics are a set of metrics to evaluate [[Object Oriented Programming|object oriented programming]]
• Cohesion – Aim to make responsibilities of a module or class closely related to each other.
• Coupling – Aim for weak interconnection between classes and between components.
• Primitiveness – Aim for functions that are composed only by fundamental/elementary operations.
• Sufficiency – Aim to ensure that the code does the bare minimum it’s supposed to.
• Completeness – Aim to ensure that classes capture enough details to be re-usable.
