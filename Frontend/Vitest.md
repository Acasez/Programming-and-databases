Vitest is a [[Vite]] addon for doing [[Unit Testing]] using [[JavaScript]]/Typescript.

It uses "it" statements to test statements

Vitest tests functions and DOM layout, but does not "click around" like a human does. It can test backend API calls and [[React]] components using another addon called React Component Testing (RTL)

It's connected to Vite and understands if you are using React or a frontend framework
Vitest can also be run as a UI with the Vitest UI addon
There is also a addon for code coverage. 

Vitest can be run in the terminal automatically with `npx vitest`
