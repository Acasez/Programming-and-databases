JavaScript is a programming language used in [[Web Development]]. Its the most used programming language on GitHub.

JavaScript is mostly used for web development and it's the only one that websites understand natively. It can also be used outside of web using frameworks like NodeJS. 

[[TypeScript]] is a JavaScript superscript to use JavaScript static typed, as JavaScript allows dynamic typing.

VS Code, Discord and Spotify are made in JavaScript. 

JavaScript have many [[Arrow Functions]] (=>) that make more compact code 

JavaScript can be run [[HTTP Communication]], using await fetch methods
