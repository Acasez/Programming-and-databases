Typescript is a [[Programming Languages/JavaScript]] superset that adds explicit typing like C#. You define what types a function takes in as parameters and returns

Websites don't understand Typescript so you need to compile it into JavaScript to run. You can use a build tool like [[Vite]] to compile automatically. 

TypeScript has interface, which sort of works like C# interfaces but is mostly for defining an object with multiple varibles

Union types that let you have a variable with two types. 
let variable: number | string
