To get a on overview of [[The Internet]] networks we break into layers. At different layers encapsulation is added to the message. 

| Layers                             | [[Protocols]] | Description                                                                    |
| ---------------------------------- | ------------- | ------------------------------------------------------------------------------ |
| [[Application Layer\|Application]] | [[HTTP]]      | Supporting network applications                                                |
| [[Transport Layer\|Transport]]     | [[TCP]]       | Process-process data transfer, packages message with headers                   |
| [[Network Layer\|Network]]         | [[IP]]        | Routing of datagrams from source to destination, adds network specific headers |
| [[Link Layer\|Link]]               | Ethernet      | Transfers from host to host, adds network-layer solutions.                     |
| Physical                           | ----          | Physical media                                                                 |
