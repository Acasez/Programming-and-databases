Firewalls are setup to block traffic from specific [[IP Address|IP addresses]], improving [[Network Security]] (or censuring political speech).

A screen with administered network on side and dangerous elements on the other side.

Can prevent denial of service attacks.

Filters packet-by-packet based on source/destination IP address, TCP/UDP source, destination port numbers, ICMP message type, TCP SYN, ACK bits
