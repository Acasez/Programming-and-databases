Public key [[Cryptography|cryptography]] is the second of the two main methods of [[Encryption]]
Public key crypto
	- Radically different method, revolutionize cryptology.
	- No shared key, public key is known to all.
		- Should be impossible to get private key from public key
	- Private decryption key, only known to receiver
		- RSA method on how this works.
	- Exponential calculations, very expensive. Slower and requires more computing power than symmetric key crypto.
	- Used to establish secure connections, then exchange and use symmetric keys.
