Applications on the [[Application Layer|application layer]] sends messages to/from its socket. A socket is like a door for application, where it sends and gets messages. When messaging each side has two sockets, one for sending and one for receiving. 

Host device have an identifier, the host has a 32-bit IP-Address. Sockets also have a port number to specify, as many processes are often running on the host server. 

Sockets are the [[API]] between application layer and the [[Transport Layer|transport]] layer beneath it. 
[[Socket Programming]] can be done with sockets to interact with the transport layer.
