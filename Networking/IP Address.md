The address on the used by the [[IP]] on the [[Network Layer|network]]. 

CIDR, Classless InterDomain Routing
Address format.
[[Subnet]] format comes first

How do you get an IP Address? 

Used to be hardcoded, now assigned when joining a network using the DHCP, Dynamic Host Configuration Protocol.
The DHCP can offer an address, or the client can ask to reuse one. 

The DHCP can also provide the address of the first-hop router for the client, the name and IP address of the [[DNS]] server and the network mask.

IPv4 has run out of IP addresses, [[IPv6]] can fix that. Can also use Network address translation ([[NAT]]) to compress IP addresses to get more address space, which makes all devices in local network/subnet share one IP address.
