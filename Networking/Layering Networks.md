To get a on overview of network we break into layers. At different layers encapsulation is added to the message. 


| Layers      | Protocols | Description                                                                    |
| ----------- | --------- | ------------------------------------------------------------------------------ |
| Application | HTTP      | Supporting network applications                                                |
| Transport   | TCP       | Process-process data transfer, packages message with headers                   |
| Network     | IP        | Routing of datagrams from source to destination, adds network specific headers |
| Link        | Etherenet | Transfers from host to host, adds network-layer solutions.                     |
| Physical    | ----      | Physical media                                                                 |
