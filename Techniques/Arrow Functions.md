Arrow Functions are 
Iteration  
forEach — loopa igenom (ingen return)  
map — returnerar ny array  
filter — returnerar ny array  
reduce — returnerar ett värde  
reduceRight — samma som reduce men baklänges

Sökning  
find — returnerar första matchande elementet  
findIndex — returnerar index  
findLast — senaste matchande elementet  
findLastIndex — index för senaste matchningen  
includes — true/false om värdet finns  
indexOf — första förekomsten  
lastIndexOf — sista förekomsten  
some — true om något element matchar  
every — true om alla matchar

Sortering & omstrukturering  
sort — sorterar arrayen (muterar!)  
reverse — vänder arrayen (muterar!)  
toSorted — sorterar utan mutation  
toReversed — vänder utan mutation  
flat — plattar ut arrayer  
flatMap — map + flat i ett steg

Skapa nya arrayer  
slice — kopia av del av array  
concat — slå ihop arrayer  
toSpliced — icke‑muterande version av splice
